An der Küste des südbrasilianischen Bundesstaates Santa Catarina gehört das Surfen fest zum Alltag vieler Menschen. Lange Sandstrände, beständige Wellen und die Nähe zum Atlantik schaffen Bedingungen, die Einsteiger ebenso anziehen wie erfahrene Surfer. Wer hier auf das Meer hinausblickt, erkennt schnell, dass Geduld ein wichtiger Teil dieses Sports ist. Zwischen den heranrollenden Wellen warten die Surfer aufmerksam auf den richtigen Moment. Sie beobachten Wind, Strömung und Wellengang, bevor sie sich für eine einzelne Welle entscheiden.
