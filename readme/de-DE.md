[2026-11-13 Verborgene Tiefen Abraham Lake in Alberta, Kanada(© Guang Cao/Getty Images)](https://www.bing.com/th?id=OHR.AbrahamCanada_DE-DE1158881043_UHD.jpg)
Das erste Licht der Morgendämmerung spiegelt sich auf dem vereisten Abraham Lake, eingerahmt von den Gipfeln der Rocky Mountains. Im Winter ist dieser malerische See in Alberta berühmt für seine gefrorenen Blasen aus Methangas, die unter dem Eis eingeschlossen sind. Starke Winde halten die Oberfläche schneefrei und sorgen so den ganzen Winter über für einen freien Blick. Im Frühling, wenn das Eis schmilzt, entweicht das Gas in die Atmosphäre.
