[2026-09-09 Leben an Indiens Westküste Gabit-Keni-Strand bei Ankola, Karnataka, Indien(© Amith Nag Photography/Getty Images)](https://www.bing.com/th?id=OHR.GabitKeni_DE-DE7644159107_UHD.jpg)
An der Westküste Indiens, im Bundesstaat Karnataka, liegt der Gabit-Keni-Strand nahe der Stadt Ankola. Der breite Sandstrand öffnet sich zum Arabischen Meer und vermittelt eine ruhige, fast unberührte Atmosphäre. Besonders in den frühen Morgenstunden prägen Fischerboote das Bild, wenn sie hinausfahren und später mit ihrem Fang zurückkehren. Die Nähe zum Meer bestimmt hier seit Generationen den Alltag vieler Menschen.
