# Latest Wallpaper
![](https://www.bing.com/th?id=OHR.FibonacciFern_DE-DE6300100112_UHD.jpg)
[2026-11-23 Geometrie in der Natur Farnspitzen(© Reza Saputra/Getty Images)](https://www.bing.com/th?id=OHR.FibonacciFern_DE-DE6300100112_UHD.jpg)
Das heutige Bild zeigt die Windung der Spitze eines jungen Farnsprosses, die an die geometrischen Muster erinnert, die überall in der Natur zu finden sind. In der Mathematik folgt die Fibonacci-Folge (benannt nach dem italienischen Mathematiker Leonardo Fibonacci) einem ähnlichen Muster, wobei jede Zahl durch die Addition der beiden vorhergehenden Zahlen entsteht: 0, 1, 1, 2, 3, 5, 8 und so weiter. Heute ist der Fibonacci-Tag, der aufgrund der amerikanischen Schreibweise des Datums (11/23) zu Ehren dieser Folge gewählt wurde.
