Die Îles Sanguinaires sind eine kleine Inselgruppe vor der Westküste Korsikas in Frankreich. Am Eingang des Golfs von Ajaccio ragen vier markante Felseninseln aus dem Mittelmeer empor. Von der Küste aus bieten sie ein eindrucksvolles Panorama, das von den kräftigen Farben des Meeres und den dunklen Granitfelsen geprägt wird.
