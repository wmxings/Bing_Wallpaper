# Latest Wallpaper
![](https://www.bing.com/th?id=OHR.SunsetPoint_DE-DE0548911114_UHD.jpg)
[2026-11-25 Schneefall im Südwesten Sunset Point, Bryce-Canyon-Nationalpark, Utah(© Colin D. Young/Alamy)](https://www.bing.com/th?id=OHR.SunsetPoint_DE-DE0548911114_UHD.jpg)
Schnee verwandelt den Bryce-Canyon-Nationalpark und hüllt die Landschaft in Weiß, während sich die feurig orange-roten Hoodoos über das verschneite Gelände erheben. Vom Sunset Point aus, einem der berühmtesten Aussichtspunkte des Parks, betrachtet, sind diese fantasievollen Formen Teil der Claron-Formation, deren Kalkstein vor etwa 50 Millionen Jahren abgelagert und später durch Verwitterung und Erosion geformt wurde. Da ein Großteil des Parks über 2.400 Meter hoch liegt, kann es bereits im Oktober schneien. Auf dem heutigen Bild liegt Schnee auf den Graten und Felsspitzen des Canyons, während Nebel über die Klippen zieht und so eine einzigartige Winterlandschaft im Südwesten der USA schafft.
