[2026-08-18 Étoilée et italienne Vue aérienne de Palmanova, Friuli, Italie(© Riccardo Saponi/Getty Images)](https://www.bing.com/th?id=OHR.Palmanova_FR-CA6927775501_UHD.jpg)
Vue du ciel, Palmanova évoque une gigantesque étoile posée sur la plaine du Frioul-Vénétie Julienne, dans le nord-est de l’Italie. Fondée en 1593 par la République de Venise, elle incarne une idée audacieuse : réunir l’art, la science et la défense dans une même conception urbaine. Depuis sa vaste place centrale, les rues rayonnent selon un plan d’une précision remarquable, tandis que les remparts dessinent une figure à neuf pointes visible jusque dans les moindres détails depuis les airs.
