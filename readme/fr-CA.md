Alors que les premières gelées de l'automne s'installent dans le sud des États-Unis, des cristaux de glace se forment sur les feuilles persistantes d'arbustes comme cette azalée. Les fleurs roses, orangées et jaunes du printemps ont depuis longtemps disparu, mais un nouveau spectacle de couleurs prend le relais lorsque les feuilles vertes se parent de teintes rouges et pourpres. Pour la plante, ces pigments agissent comme une protection contre le froid; pour les jardiniers, ils offrent un magnifique décor automnal rehaussé par le blanc du givre. Au retour du printemps, une nouvelle croissance ramène le feuillage vert, et le cycle des couleurs recommence une fois de plus.
