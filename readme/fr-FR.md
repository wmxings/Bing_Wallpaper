Sous l’Arc de Triomphe repose le Soldat inconnu, symbole de tous les combattants morts pour la France durant la Première guerre mondiale. Sa tombe, sur laquelle brûle la flamme du souvenir, ravivée chaque soir, invite au recueillement et perpétue la mémoire de ceux qui ont donné leur vie pour leur pays. Le jour de l'Armistice, une gerbe y est déposée.
