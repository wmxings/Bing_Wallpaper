Le sol tremble avant même qu’on les voie. Dans le Masai Mara, au Kenya, plus d’un million de gnous convergent vers la rivière Mara, guidés par un instinct ancien, inscrit dans l’espèce. Sur la berge, le troupeau s’accumule, hésite, puis bascule. En quelques secondes, des milliers de corps plongent dans les eaux brunes et rapides dans un fracas de cornes, de sabots et d’éclaboussures.
