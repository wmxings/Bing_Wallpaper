[2026-08-11 Copenhague haute en couleur Maisons colorées sur les rives du canal Nyhavn, Copenhague, Danemark(© emicristea/Getty Images)](https://www.bing.com/th?id=OHR.ColorfulCop_FR-FR8595384019_UHD.jpg)
À Copenhague (Danemark), Nyhavn est un véritable tableau vivant où les couleurs éclatantes se mêlent à plusieurs siècles d’histoire. Le long de ce canal d’environ 457 mètres, les maisons à pignons se penchent vers l’eau, leurs reflets dansant à côté de vieux navires de bois. Creusé dans les années 1670 sous le roi Christian V, cet axe navigable constituait autrefois une porte d’entrée majeure pour les marchandises arrivant directement au cœur de la capitale danoise. Les marins y trouvaient aussi refuge, ce qui valut au quartier une réputation bien différente de celle qu’on lui connaît aujourd’hui.
