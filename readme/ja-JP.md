夕暮れ時になると、ヴロツワフの歴史ある街並みが黄金色の光に包まれます。ポーランド南西部に位置するこの都市は、同国で最も古い都市の一つです。100 以上の橋で結ばれた水の都として知られ、中世の面影と現代の活気が調和しています。中心部には、13 世紀に開かれたリネク広場と旧市庁舎があり、多くの人でにぎわいます。画像は、聖マリア・マグダレーナ教会の「魔女の橋」から望んだ眺めです。旧市街や広場を一望でき、やわらかな灯りに照らされた街の幻想的な美しさを楽しむことができます。
