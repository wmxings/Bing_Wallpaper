[2026-10-29 草原に立ち並ぶ巨石群 エーヴベリー 巨石群, イングランド(© George W Johnson/Getty Images)](https://www.bing.com/th?id=OHR.AveburyStones_JA-JP4031336786_UHD.jpg)
イングランド南西部ウィルトシャーにあるエーヴベリー。朝霧に包まれた巨石群は、約 4500 年前の新石器時代に築かれた遺跡の一部です。世界最大の先史時代の環状列石をはじめ、巨大な環状遺構や列石が残されており、シルベリー・ヒルなど周辺の遺跡とともに広大な遺跡群を形成し、ユネスコ世界遺産にも登録されています。訪れる人は巨石の間を歩くことで、現代の田園風景に溶け込む古代遺跡を間近に体感することができます。
