エリリ国立公園（旧スノードニア国立公園）は、面積約 2,130km² を誇るウェールズ最大の国立公園です。1951 年の今日、10 月 18 日に国立公園に指定されました。公園内には、ウェールズ最高峰のイール・ウィドファ（旧スノードン山）がそびえるなど、雄大な山岳風景が広がっています。そして画像は、公園内にあるドルバダーン城。13 世紀に築かれたウェールズを代表する城のひとつで、特徴的な円塔が美しい景観の中にたたずんでいます。
