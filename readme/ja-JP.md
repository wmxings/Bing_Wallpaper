[2026-11-02 氷がつなぐ未来 ホッキョクグマの親子、ハドソン湾、マニトバ州、カナダ(© Danita Delimont/Adobe Stock)](https://www.bing.com/th?id=OHR.HudsonBear_JA-JP9155678647_UHD.jpg)
カナダ・マニトバ州のハドソン湾沿岸では、ホッキョクグマたちが、海氷が張るのを待っています。海氷ができると、再び氷の上でアザラシを狩れるようになります。11月の第1週には「ホッキョクグマ週間」が行われます。泳ぎも狩りも得意な彼らは、地球上でも指折りの厳しい環境に適応して暮らしています。しかし、海氷の減少によって陸上で過ごす時間が長くなり、餌を確保しにくくなるなどの影響が出ています。写真に写っているのは、ハドソン湾近くで暮らす母グマと子グマたちです。この愛らしい親子の姿は、北極の美しい自然と、ホッキョクグマが生きるために欠かせない海氷を守る大切さを伝えています。
