[2026-09-27 今日は横浜ベイブリッジ開通日 横浜ベイブリッジ, 神奈川県 横浜市(© Yuga Kurita/Getty Images)](https://www.bing.com/th?id=OHR.YokohamaBayBridge_JA-JP8812921625_UHD.jpg)
1989 年の今日、9 月 27 日に、横浜ベイブリッジは開通しました。横浜市の中区と鶴見区を結ぶ全長 860m の橋で、完成当時は日本最長の斜張橋でした。上層部は首都高速湾岸線、下層部は国道 357 号という 2 層構造になっています。美しい夜景スポットとして知られており、近隣の横浜港大さん橋国際客船ターミナルから月と共に撮影された姿は、日本百名月にも選ばれています。また、優れた技術力と美しいデザインが評価され、日本百名橋の一つにも選ばれています。
