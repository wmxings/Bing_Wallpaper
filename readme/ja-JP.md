今日の画像は、ベトナム・フエ市の香水川に架かるグエン・ホアン橋。全長約 380m の近代的なアーチ橋で、フー・スアン区とトゥアン・ホア区を結んでいます。2025 年 3 月 26 日に開通したもので、自動車用の車線と歩道が整備されています。地域の重要な交通インフラであり、フエの文化を取り入れたデザインが特徴です。橋の照明は王宮の天蓋をイメージしてデザインされており、伝統と現代建築が調和した美しい景観を演出しています。
