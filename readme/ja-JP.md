ドイツ・フランクフルトのフランクフルト大聖堂は、ゴシック様式の塔と中世を思わせるシルエットが印象的で、この時期らしい神秘的な雰囲気を醸し出しています。ハロウィンの風習には、収穫期の終わりと冬の始まりを告げる古代ケルトの祭り「サウィン」に由来するものがあるといわれています。当時は、この時期になると生者と死者の世界の境界が曖昧になり、超自然的な存在が現れると信じられていました。その後、11月1日が「諸聖人の日（万聖節）」と定められると、その前夜は「万聖節前夜」と呼ばれ、やがて「ハロウィン」という呼び名へと変わっていきました。
