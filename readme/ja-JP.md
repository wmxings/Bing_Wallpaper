[2026-10-03 古代の海に生息していた動物の化石 アンモナイトの化石(© J Nemchinova/Getty Images)](https://www.bing.com/th?id=OHR.AmmoniteFossils_JA-JP8778940090_UHD.jpg)
今日の画像は、アンモナイトの化石。アンモナイトは、約 4 億年前から 6600 万年前まで海に生息していた海洋軟体動物です。殻の内部が複数の部屋に分かれているなど、現生のオウムガイ類と似た特徴を持っていますが、イカやタコなどを含むグループにより近いと考えられています。多くの種類に見られる特徴的な螺旋形の殻から、古代生物の代表的な化石として広く知られています。また、世界各地で化石が発見されており、地層の年代決定や先史時代の海洋環境の研究に活用されています。
