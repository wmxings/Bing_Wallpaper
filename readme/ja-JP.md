ニューメキシコ州の断崖の洞窟には、先住民モゴヨン族が住んでいた跡が残っています。13世紀後半、洞窟に部屋をつくった人々は、土器を焼き、眼下に広がる谷で作物を育てたり狩りをしたりしていたと考えられています。ところが1300年ごろ、モゴヨン族は理由もわからないままこの地を去りました。今ではアメリカ南西部でも特に重要な遺跡の一つとして知られています。
