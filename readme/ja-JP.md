[2026-11-26 虹が舞い降りる滝 ワイルク川のレインボー・フォールズ、ヒロ、ハワイ州、アメリカ(© Peter Unger/Getty Images)](https://www.bing.com/th?id=OHR.RFHilo_JA-JP7653681991_UHD.jpg)
ハワイ島ヒロにあるレインボー・フォールズでは、水と光、緑豊かな自然がひとつになった景色が広がります。ワイルク川が溶岩の岩棚から約24m下へと流れ落ち、滝つぼからは水しぶきが霧のように立ちのぼります。晴れた日の朝には、この霧に日差しが当たって虹がかかることがあり、それが滝の名前の由来になりました。ハワイ語では「ワイアーヌエヌエ」と呼ばれ、「虹の水」という意味があります。熱帯の木々に囲まれたこの滝は、古くから伝わる伝説にも登場する特別な場所です。
