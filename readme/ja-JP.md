今日の画像は、米国・ニューヨークのランドマークとして親しまれているブルックリン橋。設計者はジョン・A・ローブリングで、彼の死後、その遺志を継いだ息子夫婦が、14年の歳月をかけて 1883 年に完成させました。世界初の鋼鉄製吊り橋であり、ニューヨーク市のマンハッタン区とブルックリン区を結ぶ米国内で最も古い吊橋の一つです。その美しい景観から人気の観光地・撮影スポットとして知られるほか、古くから様々な映画のロケ地としても使用されています。
