柿は、秋を代表する果物のひとつです。生で食べるほか、干し柿などに加工して古くから親しまれてきました。そして画像は、長野県の妻籠宿で見られる干し柿の様子。秋から冬にかけて、鮮やかな柿の色が歴史ある街並みを彩ります。干し柿は、主に渋柿の皮をむいて乾燥させた伝統的な保存食です。干すことで渋みが感じられなくなり、水分が減ることで甘みが凝縮されます。作り方は地域や種類によって異なり、乾燥の途中や仕上げの段階で柿をもむなど、さまざまな工夫が受け継がれています。独特の食感と濃厚な甘みを楽しめる、秋から冬ならではの味覚です。
