[2026-11-04 秋色の森を水上散歩 色鮮やかなラクウショウの森をボートで進む人々、安徽省宣城市、中国(© Jackal Pan/Getty Images)](https://www.bing.com/th?id=OHR.AutumnChina_JA-JP2275105446_UHD.jpg)
中国・安徽省宣城市では、秋になると水に浸かったラクウショウの森が、琥珀色や銅色、深いさび色に染まります。ラクウショウは針葉樹でありながら、秋に柔らかな葉が赤褐色に変わって落ちる珍しい木です。北米では湿地に育ち、地面や水面から「膝根」と呼ばれる呼吸根を突き出すことでも知られ、樹齢1,000年を超える木の記録もあります。晩秋には葉が燃えるような色に変わり、ボートでゆったり進むと、水面にその色がきらめいて、まるで生きた絵画のようです。
