[2026-11-25 赤い奇岩の雪化粧 サンセット・ポイント、ブライスキャニオン国立公園、ユタ州(© Colin D. Young/Alamy)](https://www.bing.com/th?id=OHR.SunsetPoint_JA-JP7278727628_UHD.jpg)
雪に覆われたブライスキャニオン国立公園では、オレンジ色に輝く岩の柱「フードゥー」が白い大地からそびえ立ち、鮮やかなコントラストを見せています。写真は、園内でも有名な展望スポットのひとつ、サンセット・ポイントからの眺めです。フードゥーは、約5000万年前に積もった石灰岩の地層が、長い年月をかけて風化や浸食で削られてできたものです。公園の大部分は標高2,400mを超える高地にあるため、早ければ10月には雪が降り始めます。岩の尾根や尖塔に雪が残り、崖の間を霧が流れていく様子は、アメリカ南西部ならではの冬の絶景です。
