[2026-10-24 図書館の天窓から差し込む自然光 王立ポルトガル図書館, ブラジル(© Antonio Salaverry/Shutterstock)](https://www.bing.com/th?id=OHR.PortugueseLibrary_JA-JP3230226750_UHD.jpg)
ここはブラジルのリオデジャネイロにある王立ポルトガル図書館。ブラジルがポルトガルから独立した後、ポルトガルの言語と文化の保存・振興を目的として 1837 年に設立されました。約 35 万冊の蔵書を有し、ポルトガル国外では最大級のポルトガル語文献コレクションを誇ります。広大な閲覧室には、20m 以上の高さを誇る巨大な本棚が設置され、ステンドグラスの天窓や、アーミラリー天球儀で美しく装飾されています。設立から2世紀近くが経った今も、ブラジルとポルトガルの文化的な結びつきを伝え続けています。
