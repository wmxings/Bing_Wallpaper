今日の画像は、米国コロラド州南西部、サンファン山地にそびえるスネフェル山。標高約 4,300m を誇るロッキー山脈の名峰です。コロラド州には標高 14,000 フィート（約 4,267m ）以上の山が 58 座あり、これらは総称して「フォーティーナーズ (Fourteeners) 」と呼ばれています。スネフェル山はその中でも特に人気が高く、その美しい山容から、写真の被写体としても人気があります。秋には山麓に黄金色のアスペン林が広がり、雪をいただいた山頂との美しいコントラストが訪れる人々を魅了します。
