フランス・ノルマンディーの海に浮かぶモン・サン＝ミシェルが、夕陽に照らされて幻想的な姿を見せています。岩山の上にそびえ立つこの修道院は、ヨーロッパでも屈指の海岸景観で知られており、潮が引くと広大な干潟が現れ、満潮になると周囲を海に囲まれた島のような景観となります。その起源は 708 年にさかのぼるとされ、長い歴史の中でヨーロッパを代表するカトリックの巡礼地のひとつへと発展しました。そして、1979 年には「モン＝サン＝ミシェルとその湾」として、ユネスコの世界遺産に登録されました。
