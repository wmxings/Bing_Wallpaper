[2026-10-05 海へ飛び込もうとするペンギンたち アデリーペンギンのグループ, 南極大陸(© Otto Plantema/Minden Pictures)](https://www.bing.com/th?id=OHR.AdelieTeacher_JA-JP9090254921_UHD.jpg)
今日の画像は、南極大陸周辺に生息するアデリーペンギンのグループ。アデリーペンギンは、体長 60 ～ 70cm、体重約 5kg という中型のペンギンです。海中を時速約 14kmで泳ぎ回りながら、餌を捕まえたり、捕食者から逃れたりします。地上の雪原を移動する際は、他のペンギン同様腹ばいになって氷上を滑って移動することがあります。この移動方法は「トボガン」と呼ばれており、北米の先住民が用いていたソリを意味する言葉にちなんで名づけられました。
