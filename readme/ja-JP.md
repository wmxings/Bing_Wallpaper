アイスランドでは秋の訪れとともに夜が長くなり、オーロラ観測に適した季節が近づいています。オーロラで見られる青や緑、紫などに揺らめく光は、太陽から飛来した電気を帯びた粒子（プラズマ）が地球の高層大気中のガスと衝突することで発生します。そして、今日の画像はその幻想的な光の下にそびえるキルキュフェットル山。「教会の山」を意味する山で、晴れた夜には、この山と滝、そしてオーロラが織りなす絶景が多くの人々を魅了します。
