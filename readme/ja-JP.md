今日8月27日は「世界湖沼の日」。湖沼の重要性と保全への意識を高めるため、2024 年に国連総会で制定されました。湖沼は貴重な淡水資源であり、多様な生物を支える重要な存在です。しかし、都市化や気候変動などの影響により、その存続が脅かされています。そして、今日の画像は、ケニア南西部のマガディ湖に集まるコフラミンゴの群れ。マガディ湖は強アルカリ性で魚はほとんどいないものの、藻類が豊富であり、フラミンゴはそれを求めて集まっています。
