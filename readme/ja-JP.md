フランス・コルシカ島の沖合に浮かぶサンギネール諸島。4 つの小さな島で構成された群島で、近隣の街アジャクシオからは、島の荒々しい岩肌と透明度の高い海が織りなす景観を眺めることができます。各島には海鳥や地中海特有の植物が生息しており、その自然環境保護のため、基本的に立ち入れるのは最も大きな島であるメズ・マレ島のみです。メズ・マレ島には、灯台が設置されているほか、遊歩道も整備されており、島の散策を楽しむことができます。
