[2026-10-13 紅葉に彩られた湖と滝 プリトヴィツェ湖群国立公園, クロアチア(© Jan Wlodarczyk/Alamy)](https://www.bing.com/th?id=OHR.PlitviceAutumn_JA-JP3930294400_UHD.jpg)
ここはクロアチア中部に位置するプリトヴィツェ湖群国立公園。高低差のある 16 の湖と、それを繋ぐ 92 の滝や瀑布という壮大な景観が特徴です。湖水は、含まれるミネラルの組成や太陽光の反射によって、エメラルドグリーンから深い青までさまざまな色合いを見せます。園内には木製の遊歩道が整備されており、滝が流れ落ちる様子や澄んだ湖面、木々に囲まれた岸辺などを間近に眺めることができます。こうした圧倒的な自然美と豊かな生態系が評価され、1979年にユネスコ世界遺産に登録されました。
