![](https://www.bing.com/th?id=OHR.OmagariFireworks2026_JA-JP0416831919_UHD.jpg)
[2026-08-29 今日は大曲の花火の開催日 全国花火競技大会, 秋田県, 大仙市(© Toru Hanai/Getty Images)](https://www.bing.com/th?id=OHR.OmagariFireworks2026_JA-JP0416831919_UHD.jpg)
今日 8 月 29 日は全国花火競技大会の開催日。秋田県大仙市で行われるこの大会は、「大曲の花火」とも呼ばれ、日本三大花火大会の一つとして知られており、全国から選抜された花火師が、「昼花火の部」と「夜花火の部」で技を競います。昼花火とは、光ではなく煙で美しさを表現する花火です。また、大曲の花火最大の特徴であり、大会を象徴する競技が、夜花火の部で行われる「創造花火」。既成概念に囚われず、形や色、大きさなど全てがオリジナルの花火を、音楽にあわせて披露する競技です。
