今日の画像は、米国ユタ州ガーズマン・パス付近に広がるアスペンの森です。毎年秋になると、山々を鮮やかな黄金色に染め上げます。アスペンはヤマナラシ類の樹木で、白い樹皮と、わずかな風にも揺れて音を立てる葉で知られています。多くのアスペンは、地下でつながった根から新しい木を伸ばすため、隣接する木々が同じ遺伝情報を持つことがあります。その繁殖方法や成長の速さ、環境への高い適応力により、アスペンは山火事や伐採、地震の後にも素早く森林を再生させてくれる樹木としても知られています。
