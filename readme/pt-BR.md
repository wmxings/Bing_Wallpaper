A imagem de hoje mostra a ponta de uma jovem folha de samambaia se enrolando aos poucos, lembrando os padrões geométricos encontrados por toda a natureza. Na matemática, a sequência de Fibonacci segue uma progressão semelhante: cada número é a soma dos dois anteriores — 0, 1, 1, 2, 3, 5, 8 e assim por diante. Hoje é o Dia de Fibonacci, celebrado nesta data porque, no formato americano, 11/23 faz referência aos primeiros números da sequência. À medida que cresce, a jovem folha de samambaia mostrada aqui vai se desenrolar. Em outras partes do mundo vegetal, porém, a sequência continuará aparecendo nos padrões em espiral dos girassóis, das pinhas, das suculentas e dos abacaxis.
