在汉普郡东米恩附近的金色田野中，一棵山毛榉独自挺立，成为英格兰南唐斯国家公园起伏景观中的醒目焦点。数百年来，农业塑造着这些白垩丘陵；时至今日，耕作仍是该地区的重要组成部分。当地排水良好的白垩土壤支撑着大规模旱作农业，其中小麦和大麦是最常见的作物。整个夏季，作物在田间逐渐成熟，随后收获季将乡野变成金色田块与麦茬交织的拼图。
